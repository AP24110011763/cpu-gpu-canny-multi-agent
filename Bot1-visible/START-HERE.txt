BOT 1 - setup with NO hidden files

PART A - upload the main files
1. Open the folder "1-UPLOAD-THESE". It contains: bot1 and inbox.
2. On github.com open your repo -> Add file -> Upload files.
3. Drag in bot1 and inbox. Commit directly to main.

PART B - create the two workflow files (typed in the browser, nothing hidden)
Do this once for EACH file in "2-CREATE-THESE-TWO-FILES-ON-GITHUB":
1. On github.com in your repo: Add file -> Create new file.
2. In the name box type exactly:   .github/workflows/bot1-inbox.yml
   (typing the "/" makes the folders automatically)
3. Open bot1-inbox.yml from this folder in TextEdit/Notepad, select all, copy, paste into the big box on GitHub.
4. Click Commit changes -> commit directly to main.
5. Repeat with the name:           .github/workflows/bot1-activity.yml
   and the contents of bot1-activity.yml.

PART C - permissions
Repo -> Settings -> Actions -> General -> Workflow permissions -> "Read and write permissions" -> Save.

TEST: upload any file into the repo's "inbox" folder. In about a minute it moves to the right folder
and the issue "Repo Activity Log (Bot 1)" shows what happened.
